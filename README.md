### 📌 Featured Projects

🛡️ **Host-Based DoS Attack Detector**
A Python detection-and-response tool that analyzes live network traffic to spot rate-based denial-of-service attempts using a sliding-window algorithm, with automated IP blocking via firewall controls, auto-restore, and whitelisting.

🔍 **[File Type Identifier](https://github.com/Doquanglong/magic-number-file-identifier)**
A Python tool that identifies a file's true type by parsing magic-number byte signatures, defeating extension-spoofing used to disguise malicious files — built with zero external dependencies.

🌐 **Web Application Recon Automation**
